## [1.0.0](https://github.com/HastaCs/MultasExporter/releases/tag/v1.0.0) (2026-10-11)

### 🚀 Features

- 📄 Lector de PDFs de multas de tráfico que devuelve un JSON homogéneo: vehículo, fecha, expediente, organismo emisor, motivo, lugar e importe.
- 🏛️ Soporte multi-organismo con extractores por plantilla (DGT, ayuntamientos, diputaciones y agencias autonómicas).
- 🔌 API REST para subir PDFs o ZIPs y obtener el JSON por HTTP.
- 🖥️ Aplicación de consola como herramienta de desarrollo.
- 🐳 Imagen Docker lista para desplegar.
