# Contribuir a Multas Exporter

¡Gracias por querer aportar! 🚗

## Reglas

1. **Un extractor por Pull Request.** No agrupes varios organismos o plantillas
   en la misma PR: así se revisa mejor y se aísla cada formato.
2. **Adjunta el PDF de la multa de ejemplo mediante un enlace externo**
   (Drive, Dropbox, WeTransfer…). Es necesario para poder **comprobar que el
   extractor funciona correctamente**; sin él la PR no se puede validar.
   Una vez verificado, **retira el enlace**.
3. **No hagas commit del PDF.** Si lo commiteas, aunque lo borres después,
   permanecerá en el historial de git.
4. **Commits convencionales** (`feat:`, `fix:`, `docs:`…) para el versionado automático.
